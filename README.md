# 🧹 CleanIT

See what's filling your drives, and clear it. A modern take on WizTree for Windows: a fast scanner, a clickable map of every folder, smart clean-up suggestions, and a built-in AI that explains what's taking up space. Built in Rust.

## ⬇️ Download

**[Get the latest version here](https://github.com/heyjeay/cleanit_public/releases/latest)**: under **Assets**, click `CleanIT_x.x.x_x64-setup.exe`.

Prefer no install? Grab `CleanIT_x.x.x_x64-portable.exe` instead: one file, runs from anywhere, even a USB stick.

## 📦 Install guide

**1. If your browser complains about the download:**
- **Chrome:** click the download arrow → **Keep**
- **Edge:** `⋯` menu on the download → **Keep** → **Show more** → **Keep anyway**

**2. Run the setup.** If Windows shows the blue **"Windows protected your PC"** screen:
- Click **More info**
- Click **Run anyway**

> This shows up because CleanIT is an indie build, not from a big-name publisher. It only asks the first time.

**3. Follow the installer.** No admin rights needed; it adds CleanIT to your Start menu.

**4. Open CleanIT and pick a drive.**

## ✨ What it does

| | |
| --- | --- |
| 🗺️ **Map** | Every folder as a block sized by what it holds. Click to zoom in, scroll to zoom in and out, right-click for actions. |
| 📄 **Files** | The 1,000 biggest files or folders, with search and type filters. Tick several to clear them at once. |
| 🧹 **Clean up** | Caches, temp files, old installers, Google Takeout exports, duplicates and game leftovers, each marked **Safe** or **Review**. |
| ✨ **Explain with AI** | Right-click anything: what it is, why it's so big, and whether it can go. Runs on your PC, free and offline. |
| ⚡ **Fast scan** | Click **Fast scan** in the top bar to restart as administrator: drives are then read straight from the NTFS file table, WizTree-fast. |

The first time you use **Explain with AI**, CleanIT downloads its AI model once (about 1 GB). After that it works offline, and nothing about your files leaves your PC.

## 🔄 Updates

CleanIT **updates itself**. When a new version is out, a blue **Update** pill appears in the top bar: one click installs it and reopens the app. You never need to come back to this page.
